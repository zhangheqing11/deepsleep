# 睡眠领域脱敏标注规范 v0.3

> v0.3（2026-11-14，项目负责人拍板）：**日历日期与精确年龄原样保留**，不再泛化。理由：这两类信息不与其他信息组合时不构成"可识别"，而其精确值可能涉及临床或法律判断（如起病日期、未成年/老年相关条目）。生日/出生日期仍替换。城市级地名保留。

> v0.2（2026-11-14）：依据独立审核补充 §3.10–3.13、拆出 `BIRTH_DATE`、危机 keep 跨度规则、会话别名协议、逐字一致指标。

> 用途：给本地 Qwen 做"睡眠领域特化脱敏"微调与评测。所有数据为**人工编写或模板合成**，不含任何真实来访者信息。
> 背景：通用脱敏会把时间、数字、药名、地名一律抹掉，但在 CBT-I 会谈里，"我昨天两点才睡""褪黑素吃了 3mg""从北京飞纽约倒时差"恰恰是判断干预路径（P1–P5）和转介（R0–R3）的核心证据。本规范的原则是：**只移除可识别个人的信息，睡眠临床信息一字不改**（见 §0）。

## 0. 核心思想与总原则

**核心思想：移除所有 identifiable（可识别到具体个人）的信息，其余一律保留。** 判断标准是"这条信息能否指向特定的人"，而不是"它看起来像不像敏感字段"：
- **直接标识符**（姓名、电话、证件号、账号、车牌、细粒度地址、具体单位/学校/就诊机构、生日）——单独就能定位到人或其身份锚点，必须替换；
- **非标识性属性**（钟点、日期、年龄、城市、职业、症状、药物、指标……）——不与直接标识符组合时不构成可识别，且常承载临床/法律判断所需的精确值，原样保留。直接标识符被替换后，剩下的属性也就失去了组合锚点；
- 拿不准时，问"去掉它，还能不能把这句话对回某个人？"能对回 → 替换；对不回 → 保留。

1. **最小改动**：除被标注的片段外，原文逐字保留（标点、错别字、口语、方言、表情、空格都不动）。模型不得润色、纠错、补全或总结。
2. **两类错误分开记**：漏掉身份信息（泄露）和误改临床信息（过度脱敏）是两类独立失败，分别计量（见 §6），不能用一个 F1 掩盖。严重程度：泄露证件号/电话 ≈ 改动危机表述 > 泄露姓名/地址 > 误改其他临床信息。
3. **危机/自伤表述永不改动**：哪怕句子里同时有人名、地点，危机内容本身（"想从阳台跳下去""把安眠药全吃了"）必须原样保留，下游安全层要读它。

## 1. 要处理的类别（REDACT）

| 标签 | 范围 | 处理 | 输出 |
|---|---|---|---|
| `PERSON` | 真实姓名、带姓的称呼（张医生→姓）、指向特定人的小名/昵称（"小雨""阿杰"） | 替换 | `[人名N]`；"张医生"→`[人名N]医生`（称谓保留在外） |
| `PHONE` | 手机、座机、带分隔/空格/+86/汉字数字的号码 | 替换 | `[电话N]` |
| `ID_NUM` | 身份证、护照、社保/医保卡号、病历号、住院号、门诊号、学号、工号 | 替换 | `[证件号N]` |
| `ACCOUNT` | 微信号、QQ 号、邮箱、各平台用户名/网名、银行卡号 | 替换 | `[账号N]` |
| `PLATE` | 车牌 | 替换 | `[车牌N]` |
| `ADDRESS` | 区/县级以下的地址：街道、路名门牌、小区、楼栋单元、村 | 替换（连续地址整段替成一个） | `[地址N]`；省/市前缀保留："天津市南开区卫津路92号"→"天津市[地址1]" |
| `ORG` | 具体工作单位、公司、政府机关、社团名称（"华为""天津某某科技有限公司"） | 替换 | `[单位N]` |
| `SCHOOL` | 具体学校名（"天津大学""南开中学"） | 替换 | `[学校N]` |
| `HOSPITAL` | 具体医疗/心理机构名（"天津医科大学总医院""某某心理咨询中心"） | 替换（科室保留） | `[医院N]`；"总医院睡眠科"→"[医院1]睡眠科" |
| `BIRTH_DATE` | 任何精度的生日/出生日期/出生年份/出生月份 | 替换 | `[日期N]` |

**编号规则**：同一会话内，同一实体始终用同一编号；编号按类别各自从 1 开始、按首次出现顺序递增。"张伟"和"伟哥"若明确指同一人，用同一编号；无法确定时视为不同人。

## 3. 边界与易错点（训练重点）

1. **同形词看语境**：
   - "安定"：药名（保留）／"安定门"地名（区级以下地址才改，"安定门"是北京街道级地名→`[地址N]`）／"心里安定下来"（普通词，保留）。
   - "华为"：`在华为上班`→`[单位N]`；`华为手环显示`→保留。
   - "小米"：`小米手环`保留；`我闺蜜小米`→`[人名N]`。
   - "协和"：`协和医院`→`[医院N]`；`协和睡眠科`→`[医院N]睡眠科`。
   - "晓晨""春眠""安然""静静"等像人名的词：只有指人时才改（"静静地躺着"保留）。
2. **数字不等于号码**：AHI 32、血氧 84、睡 4.5 小时、ISI 18、"1点到5点"、"3mg"都保留；只有电话/证件/账号/车牌/卡号才改。
3. **时间与日期都保留，只有生日替换**：钟点、时长、相对时间、日历日期全部原样保留（"11月3号那天两点才睡"不改）；"我生日是5月17日""我1998年出生"→`[日期N]`。
4. **"我在医院上夜班"**（泛指）保留；**"我在天津市第一中心医院当护士"**→"我在[医院1]当护士"（职业保留）。
5. **城市保留、街道替换**："住在成都高新区天府三街的小区"→"住在成都[地址1]的小区"；时差与气候信息不丢。
6. **称谓保留、名字替换**："我老公张磊打呼噜"→"我老公[人名1]打呼噜"。
7. **年龄原样保留**："我今年34岁了"不改；但"我是1990年出生的"是出生年份→`[日期N]`。
8. **不要多删**：句中没有身份信息时，输出必须与输入**完全一致**（hard negative，数据集中占比 ≥ 30%）。
9. **危机句也照常脱敏身份**："我住在阳光花园12栋，想从楼顶跳下去"→"我住在[地址1]，想从楼顶跳下去"。危机内容保留，地址照改。
10. **机构/品牌要有身份关系才改**：只有明确是来访者本人或其关系人的单位、学校、就诊机构时才 REDACT（"我在美团上班""我老公在腾讯""我在协和看过"）；只作为产品、App、新闻、话题提到时保留（"睡前刷美团外卖""看到腾讯的新闻""苹果手机"）。关系不明时保留——合成数据不得出现"没有关系证据却标 ORG"的样本。
11. **危机 keep 写完整分句**：危机样本的 keep 必须是包含意图/行为词、否定词、时态词（想过、以前、现在没有了、不会）和主语的完整分句，如"想过把攒的安眠药一次全吃了"而不是"把攒的安眠药一次全吃了"。删掉"想过"会把念头变成行为，评测必须能抓到。
12. **床号、房间号保留**：病床号、宿舍号、病房号是短期情境信息，不单独指向个人，保留（"三号床""302宿舍"）。门牌号属于地址，照 ADDRESS 处理。
13. **会话别名**：同一会话中明确指同一人的不同称呼（"我老公王涛"……"涛子"）共用一个编号。extract 输出里，别名实体带 `"same_as":"[人名1]"`；代码只在该占位符已存在于本会话映射时采纳，否则按新实体编号。

## 4. 两种训练任务格式（推荐 extract）

- **extract（推荐）**：模型只输出 JSON 实体列表，替换和编号由代码完成。好处：未标注的原文由代码保证逐字不变，模型不可能"顺手改写"临床内容；会话级编号映射也由代码维护。
  ```json
  {"entities":[{"text":"张磊","label":"PERSON"},{"text":"1998年5月17日","label":"BIRTH_DATE"}]}
  ```
  所有标签都是替换类，不带 `replacement`，由代码分配 `[人名N]` 等占位符（会话别名用 `same_as`）。同一 surface 若在句中有不同处理（"小米是我朋友，我戴小米手环"），按 (text,label) 分组各自给 `occ`（第几次出现，1 起算）。会话模式下 user 消息附带本会话已有映射，别名用 `same_as`（§3.13）。
- **rewrite**：模型直接输出脱敏后整句。实现简单，但需在推理后校验"keep 片段全部原样出现"，否则回退规则版。

## 5. 数据文件格式

每条样本一行 JSON（`gold/*.jsonl`）：

```json
{
  "id": "seed-001",
  "text": "原句",
  "entities": [{"start": 4, "end": 6, "text": "张磊", "label": "PERSON", "replacement": "[人名1]"}],
  "keep": ["两点", "打呼噜"],
  "deid": "脱敏后句子",
  "tags": ["person", "time_keep"],
  "note": "可选，说明为什么这样标"
}
```

- `deid` 必须等于用 `entities` 对 `text` 做替换的结果（`tools/validate.py` 检查）。
- `keep` 列出本句里**必须原样存活**的 1–6 个关键临床片段（短语或分句，不是整段原文），评测时按原文位置对齐，检查是否在输出中原样存活（§6）。
- 多轮会话（`gold/sessions.jsonl`）额外有 `session_id`、`turn`，编号在整个会话内连续。

## 6. 评测指标

| 指标 | 定义 | 目标 |
|---|---|---|
| 泄露率 | 金标实体原文仍出现在输出中的比例 | 越低越好，PHONE/ID_NUM 必须 0 |
| 临床保留率 | `keep` 片段在**原位置**原样存活的比例（按原文位置对齐输出，占位符区域不算） | ≥ 99% |
| 危机保留率 | 带 `crisis` 标签样本的 keep 片段保留率 | 100% |
| 非实体区逐字一致率 | 输出与原文对齐后，金标实体以外的字符全部未变的样本比例 | ≥ 98% |
| 有效输出率 | 模型输出可解析（extract 为合法 JSON 且实体都在原文中） | ≥ 99%，无效输出不得当作"未改动"计分 |
| 过度脱敏率 | hard negative 样本中输出 ≠ 输入的比例 | ≤ 2% |
| 整句精确匹配 | 输出 == 金标 `deid` | 参考 |
