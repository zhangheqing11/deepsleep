# 词表来源与用途

全部离线人工整理，无外部爬取或真实来访记录。KEEP 词汇不是无条件白名单；必须看完整语境。REDACT 姓名、昵称、地址、联系方式仅作虚构生成组件；真实城市、品牌、企业、学校、医院为公共名称，任职/就读/就医关系均为虚构。机构现行全称未联网核验。

TXT/YAML 文件均以 `#` 写明用途/来源；`ambiguous.jsonl` 为严格 JSONL，不插入非法注释行，其来源说明为本文件及各行 note。每条 surface 可能只是完整实体的一个子串，例句的 label 指完整实体，如“3号”所在的“眠溪路3号”为 ADDRESS、“11月3号”为 KEEP；不能只替换 surface。

危机来源与摘录方式见 [keep/README.md](keep/README.md)。号码的格式说明见 `redact/patterns.yaml`，正确校验位不表示真实号码验证或保证未分配。日期/年龄由生成器作为 KEEP 素材，不经过泛化函数。

v0.3：生日/出生年月（任何精度）使用 `BIRTH_DATE`，普通精确日历日期和年龄（阿拉伯/汉字、“刚满61”“三十四了”）均原样保留，不再有 DATE/AGE 实体；城市保留，所有标签都是占位符替换类。`ambiguous.jsonl` 各行显式 `context_required: true`；机构名仅有任职、就读、就诊或关系人证据才 REDACT。床号、宿舍号、病房号保留，门牌归连续 ADDRESS。

号码虽为生成但格式有效，现实分配状态未知，严禁拨打、查询或联系验证。身份证保留真实18位形状与校验位，银行卡保留 Luhn 形状，供模型学习格式；这不保证任何一个号码在现实中未分配。没有联网查号或修改真实数据。

词表是召回素材，合成器使用更窄的场景池：饮品配“喝”、烟/电子烟配“抽”、药物/补充剂配“用”或“吃”；屏幕、睡眠监测和游戏机分别填槽；App 带类型动词；同住关系才配睡着/打鼾场景。药名没有被统一称为“失眠药”，也不暗示即时效果。YB/MZ/ZY/BL 分别用于医保卡/门诊/住院/病历，18位身份证仅用于身份证语境。
