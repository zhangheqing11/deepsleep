# DeepSleep 静态界面原型

> **本原型没有符合项目要求的危机安全层，不得直接使用；正式前端必须接团队的 `safety/`，不得沿用本原型的正则。**

本目录只用于评审页面结构、响应式样式和交互文案。所有案例、时间、灯光、记忆与评分都是静态示意；没有聊天 Agent、真实设备控制、浏览器扩展、备份导入或持久化。请勿输入真实个人信息。比赛前端以仓库 `contracts/` 的数据契约和正式 `web/` 实现为准。

在仓库根目录执行 `cd design && python3 -m http.server 4173`，打开 `http://localhost:4173/prototype/`。页面的“对话”和“个性化设置”可通过静态锚点查看，两处都不会执行外部调用。`npm test` 运行范围与备份路径的静态回归检查，无需安装依赖。

页面结构供前端负责人参考：对话入口先询问起床与收尾时间，再展示今晚准备时间；个性化设置集中作息偏好和演示版灯光卡；右侧示意反馈记忆与版本差异。显示的学习对比只是布局示意，不是比赛运行报告。正式前端应从团队的 `run_report` 和 `evolution` 契约读取真实数据。所有界面文字均待团队统一审定，尤其是风险提示和健康边界文案。
