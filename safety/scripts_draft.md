## 1. `safety_check`（被动意念，插入后会谈继续）

**推荐版（54 字）**

> 听起来你现在很不好受。我想先确认一下：你现在安全吗，有没有想过伤害自己，比如已经想好怎么做，或者准备了什么？

**备选版（48 字）**

> 谢谢你愿意说出来。我想直接问一句：你现在有没有想过伤害自己，比如已经想好怎么做，或者准备了什么？

**取舍**

- 推荐版第一句先接住感受，用"听起来"，不贴标签。第二句先问"现在安全吗"，再展开想法、计划、准备，一次问清，对方回一句"没有"或"有想过"就够。
- 推荐版的问句比备选版多一层，稍长，对方可能只答"安全"而漏答"有没有想法"。备选版只有一个问题，更好答，但开头只有道谢，接住感受较弱。
- 第一句没有复述来访原话（例如"睡过去别醒"）。这句话也会被 PHQ-9 第 9 题触发，那时来访并没有说过原话，复述反而突兀。
- 不加任何安慰或劝说，也不提保密。

## 2. `history_check` 兜底句（只在 agent 下一句没核验时插入）

**推荐版（52 字，一句话）**

> 谢谢你愿意说出来，这不容易，我只想确认现在的情况：最近一个月，你还有没有这样的念头，或者伤害自己的行为？

**备选版（43 字）**

> 这些话说出来不容易，谢谢你告诉我，想问一下现在的情况：最近一个月，你还有这样的念头吗？

**取舍**

- 推荐版同时核验"念头"和"伤害自己的行为"，覆盖过去提到的自伤或尝试。句子偏长，但只问现在，不问细节。
- 备选版更短，只核验念头，是非题，最好答。如果来访过去提到的是自伤或尝试，它不涉及行为，核验面略窄。
- 两版都用逗号和冒号连成一句。**不要在"现在/最近"和"念头"之间加句号。** 正则的中间段不允许跨 `。！？；` 和换行，加了句号就匹配不上。

**正则核对**（用 `.venv` 的 Python 对 `scripts.yaml` 里 `history_verify_patterns` 两条正则逐条 `search`，与 `layer.py` 的 `re.compile` 方式一致）

| 版本 | 第 1 条 | 第 2 条 | 命中片段 |
|---|---|---|---|
| 推荐版 | 命中 | 未命中 | `现在的情况：最近一个月，你还有没有这样的念头，或者伤害自己的行为？` |
| 备选版 | 命中 | 命中 | `现在的情况：最近一个月，你还有这样的念头吗？` |

- 推荐版命中第 1 条：开头词"现在"，触发词"还有没有"，对象词"这样的念头"，结尾是"？"。
- 备选版命中第 1 条（"现在"+"还有"+"这样的念头"+"吗"）和第 2 条（"现在"+"这样的念头"+"吗"）。
- `check_verification` 只要任一条命中即算核验，所以两版都通过。
- 建议补一条测试：断言 `scripts.yaml` 里的 `history_check` 本身能被 `history_verify_patterns` 匹配，防止以后改话术时失配。我没有改代码或测试。

## 3. `crisis_protocol`（主动意念、计划、准备、自伤行为，会谈随后终止）

**推荐版**

```
我很担心你，先把睡眠的事放一放，你现在的安全最要紧。
请把可能伤到自己的东西放远，马上联系身边信得过的人，请他来陪你。
如果已经受伤或马上要伤害自己，请立刻打 120 或 110。
求助电话：
{hotlines}
等你安全了，随时回来接着聊睡眠。
```

字数：除换行外共 119 字，已把"求助电话："和占位符 `{hotlines}` 算进去。不算这两项是 109 字。热线展开后会更长，这部分不计入 120 字。

**备选版**

```
我很担心你，先停下睡眠的话题。
第一，把可能伤到自己的东西放远；第二，联系信得过的人来陪你；已经受伤或马上要行动，请立刻打 120 或 110。
求助电话：
{hotlines}
你安全了随时回来，我们接着聊睡眠。
```

字数：103 字，口径同上。

**取舍**

- 推荐版把关心和暂停原因放在第一行（"你现在的安全最要紧"），三个步骤用口语连起来说，读起来不像清单。
- 备选版用"第一、第二"，步骤更醒目，来访情绪激动时更好抓重点，但读起来偏硬，关心的分量稍轻。
- 两版都没有"保密""会有人联系你"之类的话，也没有"我理解你的感受"。
- 两版都用"打 120 或 110"，没有写"24 小时"。
- 备选版"马上要行动"依赖上一句"伤到自己"的语境，推荐版直接写"伤害自己"，更不会歧义。

## 4. 热线列表

**YAML 片段**（不含 `hours`，全部 `verified: false`）

```yaml
hotlines:
  - name: 全国统一心理援助热线
    number: '12356'
    verified: false
  - name: 北京心理援助热线
    number: '010-82951332（手机）/ 800-810-1117（座机）'
    verified: false
  - name: 急救电话
    number: '120'
    verified: false
  - name: 报警电话
    number: '110'
    verified: false
```

说明：

- 号码、热线名称和"手机/座机"的对应关系都来自 `research/1114/3-hotlines.md`，该资料未拨打过任何热线，所以全部 `verified: false`，由心理学同学实测后再改。
- 12356 不写区号（HL-2）。12355 不单列（HL-3）。不写"24 小时""免费拨打"（HL-1）。
- 北京两个号码合成一条，对应"每条一行"和决定里的写法。如果前端要做点击拨号，可以拆成两条（"北京心理援助热线（手机拨打）""北京心理援助热线（座机拨打）"）。
- 给心理学同学的实测提示：资料显示北京 82951332 在 2026-07-22 发过系统升级公告（接通延迟），实测时留意。
- 去掉 `hours` 字段要同步改渲染代码、`SPEC.md` 第 1 节"热线列表"那一行，以及 `tests/test_safety.py` 第 156 行的测试夹具（夹具多一个 `hours` 不会报错，可留可删）。

**建议的界面展示格式**：每条一行，"名称：号码"，用全角冒号，不带括号、状态词和"占位"。

```
求助电话：
全国统一心理援助热线：12356
北京心理援助热线：010-82951332（手机）/ 800-810-1117（座机）
急救电话：120
报警电话：110
```

**渲染代码建议**（现状：`safety/layer.py` 第 135–138 行，用 `；` 拼成一行，并显示 `hours` 和"未核验，占位"，缺 `hours` 会抛 `KeyError`）

```python
hotlines = "\n".join(
    f"{entry['name']}：{entry['number']}" for entry in self.scripts["hotlines"]
)
return self.scripts[action].replace("{hotlines}", hotlines)
```

- 每条一行，跟话术里"求助电话：\n{hotlines}"的换行对得上。前端需要按换行渲染（`white-space: pre-line` 或按 `\n` 拆开）。
- `verified` 不再显示给来访。它改作内部闸门：建议在启动自检或 `make safety-eval` 里，只要有 `verified: false` 就打印一行警告，演示前清零。这属于后续代码改动，本稿没做。
