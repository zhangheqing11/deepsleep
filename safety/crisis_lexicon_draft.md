# 危机规则层词表（11/14 审核落实版）

状态：已定（11/14）：依据 `docs/review-decisions.md` 落实；其中指定保留原文的项目本次不改，正式用户文案仍走既定审定流程。

## 0. 定位与流水线

危机识别是固定规则层，**不参与进化，要求 0 漏报**（AGENTS.md 第 3 节第 5 条）。本词表是该层的第一级，后面接判断器（LLM）。流水线与契约字段的对应关系：

| 步骤 | 做什么 | 契约 `safety_source` | 契约 `safety_action` |
|---|---|---|---|
| 1 归一化 | NFKC 全半角统一、去零宽字符、去汉字间空格 | — | — |
| 2 明确档 | 无同句 past_time 时直接进危机流程 | `rule_explicit`（`judge_status=skipped`） | `crisis_protocol` |
| 2b 过去风险改道 | explicit 同句命中 past_time，走第 3 步判断器及失败兜底 | `rule_ambiguous+judge` / `rule_ambiguous` | 按第 3 / 3b 步 |
| 3 模糊档 | 命中后交判断器分档（none / history / passive / active） | `rule_ambiguous+judge` | 按判断器结果：history→`history_check`（level none）；passive→`safety_check`；active→`crisis_protocol` |
| 3b 判断器失败 | 超时、报错：模糊档**按 passive 处理**，先问一句安全确认 | `rule_ambiguous`（`judge_status=timeout` 或 `error`） | `safety_check` |
| 4 排除模式 | 只对第 3 步的模糊命中生效，**从不作用于第 2 步** | — | — |
| 5 未命中任何档 | 仍交判断器，补足规则漏检 | `judge` | 按判断器结果 |

`safety_events[].matched` 保存命中片段；规则编号通过本地 `RuleHit.entry_ids` 提供，过去时间模式通过 `past_time_ids` 提供。

## 1. 设计原则

1. **明确档要窄，宁可漏进模糊档，也不要把夸张说法判进危机流程。** 无同句 past_time 时明确档跳过判断器，误报的代价是整场会谈被危机流程终止。所以明确档只收：第一人称的自杀意愿/决定、具体方法、遗书、药物一次性全服、持刃具自伤、带时间点的终结生命。
2. **"想死""不想活"放模糊档，不放明确档。** 这两个说法在中文里同时是真实表达和高频夸张。`4-zh-suicide-detect.md` 第 6 节：HYPO-cn 夸张语料中"死"在夸张词项排名第 1，作者说明脱离上下文不能仅靠这些词判定；同节记载没有找到这些说法的自杀识别误报率原始研究。所以它们必须交给能读上下文的判断器，判断器挂了就先问一句。
3. **排除模式只能作用于模糊档。** 排除模式只收**封闭的词法构式**（"形容词+死"、"死活"、"死党"等）；赖床语境 X9 仅作上下文提示。**需要语义理解的**（第三方、新闻、过去、玩笑、自我否认）**一律不做成排除模式**，交判断器。
4. **否定词回看只写在明确档正则里，不当作排除模式。** "我没想过自杀"不应走危机流程，但不能让它整句消失，所以明确档正则自带回看，落空后由模糊档裸词"自杀"接住，交判断器。
5. **宁严勿松。** 任何一个排除模式如果可能压掉真实阳性，不作为丢弃依据；X9 已改为提示（见 LX-5）。
6. **本稿不收集任何公开词典原文。** `4-zh-suicide-detect.md` 第 2 节列了已发表的中文词典（CSD 等），但词典文件内容及许可未核实，本稿没有使用。词条是按 C-SSRS 概念和睡眠场景自写的。

### 2.1 过去时间词模式表（past_time）

已定（11/14）：以下模式仅改变路由，不直接判 history。按 `。！？!?；;\n` 切句（逗号不切句），仅同句匹配有效；别句的当前明确风险仍直接 active。

| 编号 | 覆盖 | 模式 |
|---|---|---|
| PT1 | 明确过去指称 | `以前|从前|那时候|那时|当时` |
| PT2 | 求学阶段 | `(?:小学|初中|高中|大学)(?:的时候|时|那阵子|那时候)` |
| PT3 | 多年前 | `(?:多|几|[一二两三四五六七八九十百\d]+)年前` |
| PT4 | 已长期停止 | `早就(?:不|没)|早已(?:不|没)` |

```text
PT1: 以前|从前|那时候|那时|当时
PT2: (?:小学|初中|高中|大学)(?:的时候|时|那阵子|那时候)
```

“上周”等近期表达不据此自动改道；即使改道也必须由判断器区分当前仍有与过去已结束。

执行规则（写成代码时必须照此实现）：
1. **逐命中处理**：每个模糊命中单独判断是否被排除。一句话里只要还有**未被排除的**模糊命中，整句仍交判断器。例：“困死了，但我不想活了”仅排除程度补语的“死”，其余命中仍交判断器。
2. **明确档先判，且不受排除影响。** 先跑第 2 节；无同句 past_time 时走 `rule_explicit`，有同句 past_time 时走判断器路径，排除模式都不能抵消明确档命中。
3. 排除模式**只写封闭词法构式**。刻意没写成排除的：
   - "累得想死""加班加得我想死"：保持交判断器，因为"想死"的夸张用法和真实表达同形（见设计原则 2）。
   - "新闻/朋友/室友"+"自杀/想不开"：交判断器。
   - "已经好了/过去的事"：交判断器。
   - "开玩笑的"：交判断器。
4. 已定（11/14）：LX-5 选 B。X9 不丢弃命中；仅附加“上下文提示：赖床/补觉语境”。DsFlashJudge 只附在 user message；Choice 类判断器附在 state 文本（Gemini SDK 的 input 文本），不改 system prompt 或 criteria。

## 6. 用测试集 `crisis_testset_draft.md` 评估“仅规则”（11/14 重算）

**口径：** 使用 `ds-safety/safety/rules.py` 与定稿 `lexicon.yaml`，运行 `make safety-eval PROVIDER=rules`。无同句 past_time 的明确命中输出 active；模糊命中或 explicit + past_time 改道输出 passive（模拟判断器失败兜底）；未命中输出 none。仅规则不能输出 history。

**history 属于应交判断器的样本**，不能再当作普通阴性并将 none 算正确。当前风险二分类仍按契约将 passive/active 记有风险，none/history 记无当前风险；历史风险另列漏核验与过度升级。下面“需处理覆盖”统计把 history 与当前风险合计为 27 条，其中明确当前风险允许直接处理。

**方法学声明：** 原词表先于原测试集编写，本次只落实审核结论（过去风险改道、X9 提示、history 标签），未针对漏报补词或反复调 prompt。词表和测试集同作者，小样本结果仅用于排错，不能外推为真实安全性能。

### 6.4 误报与过度升级

- none → passive 共 9 条：NEG-05、NEG-09、NEG-10、NEG-12、NEG-13、NEG-14、NEG-15、NEG-16、NEG-24。
- NEG-09、10、12、13 是 X9 不丢弃后的赖床语境；提示只供判断器参考，不能替代判断。
- history → passive 共 2 条：NEG-18、NEG-19；后者通过 E6 + PT2/PT4 改道。判断器成功可输出 history，失败仅兜底 passive。
- 当前明确档误报为 0；这只是这 48 条自写样本上的结果。

### 6.5 对判断器的需求

判断器必须覆盖规则未命中路径，区分本人/第三方、当前/过去已结束风险、赖床/逃避生活，并识别无死亡词的愿望与计划。已定（11/14）：history 输出 level none + history_check，下一句核验；当前仍有则按 passive/active。X9 提示不授权自动判 none，过去时间词也不授权自动判 history。
